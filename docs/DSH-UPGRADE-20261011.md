# DSH Desktop 0.2.0-rc.2 适配契约

文档版：`agenda-desktop-20261014-v2`；2026-10-14。用户已明确要求实施完整 0.4.0 方案并确认本版。实现：已完成；目标验证见 [0.4.0 验收](VERIFICATION-0.4.0.md)。

本版替代原 `dsh-upgrade-20261011-v1` 草案中的不完整宿主适配与错误提醒／会话隔离验收，承接 [SPEC F005–F008、F010](SPEC.md)，与 [节假日库契约](HOLIDAY-UPDATE-20261014.md) 一起实施。随后用户明确批准完整实现方案与本版接口细节。

## 1. Desktop 接入与既有业务

- 使用 Desktop 0.2.0-rc.2 的实际宿主服务、安装包 CLI 与精确 peer 验收；更新 0.1 的依赖约束并同步 patch／服务声明，缺少必需宿主能力时明确失败，不借旧全局 CLI 或跳过宿主测试取得通过。
- 保留日程作为用户级共享数据：多个会话／窗口访问同一 AgendaService。开发环境以独立 DSH_HOME／DSH_DATA_DIR／desktop profile 隔离，不按会话拆分业务数据。
- 保留 main／sidebar.panellist 的原生日程入口以及今天、月历、周历、待办、统计、搜索；不额外依赖 better-sidebar。
- 保留 13 个 agenda_* 工具的名称、参数、snake_case 输出与业务错误信封，捆绑 Skill 使用目标公开注册方式。公历／农历、重复待办、分类与 CSV 行为保持。
- 默认节假日改为本地 chinese-days 数据；旧年度 YAML 与旧 seed 比较基线按节假日库契约处理，不再持续写入默认年度文件。此前路径错误通过宿主包资源适配和旧基线读取验收解决。

## 2. 通信与刷新

- 保留 /agenda/ws 和既有 op-result 线协议。原生连接地址取公开 transport 的 streamBaseUrl；仅在真实 HTTP 页面使用页面地址回退。原生缺少合法回环地址时显示不可用，不能拼成 ws://app。
- 原生请求只接受精确 dsh-app://app Origin 和回环宿主，拒绝跨站标记；普通 HTTP 来源核对完整主机和端口。实际 Desktop 注册／传输不依赖旧 Web 特有服务长期等待。
- 所有成功业务写入由 AgendaService 统一发布变更，工具与页面写入共用刷新通路；串行生成／发布快照，失败不发布成功状态，客户端忽略旧连接回调。
- 取消断线写入排队：未连接时立即拒绝新操作；已发出但断线／超时的写入提示“结果未确认，请刷新核对”，不自动重放。重连仅重新建立快照基线。
- 卸载拒绝未决请求并释放连接、路由、重连／请求定时器和自有样式；重载不遗留重复注册。缓存版本及新旧连接代次回归单列。

## 3. 设置和基础体验

- 插件设置卡使用目标 plugins.bundle.config 槽，key=dsh-agenda。weekStart 保留 monday 默认及既有 sunday，保存即时更新月／周视图；业务 settings.yaml 仍为唯一保存所有者。
- 新增 update-settings 操作，参数仅为 weekStart 补丁与 expectedRevision；快照追加 settingsRevision。锁内校验修订并只更新白名单字段，保留未知键，冲突拒绝覆盖、草稿保留；成功返回完整最新快照。节假日库信息为只读摘要，不新增自动更新设置。
- 移除覆盖全部宿主 panelRow 的全局 CSS，日程样式限定自有区域并跟随真实主题变量；控件采用公开原生组件接缝，避免复制宿主私有样式。
- 编辑失败保留草稿；事件／待办弹窗提供焦点约束、Escape 关闭、关闭后焦点返回；会丢失未保存编辑时提供明确弃稿选择。
- 六个视图在一次打开期间保留各自日期、筛选与搜索状态；重启后默认进入今天。长标题可截断查看全文，窄窗口导航／表单不产生横向溢出。

## 4. 数据与验收

- 旧业务 settings.yaml／CSV 与 DSH 全局设置分开。开发只使用备份／脱敏样本，保持旧日常原件；本次不执行跨版本应用数据迁移，不自动启用日常插件或恢复 Web。
- 回归日程新增／编辑／删除，重复待办按实例完成／重开，分类、搜索统计、农历与节假日；两个会话的工具改动应同步到所有页面，不以“互不串写”误解全局共享业务。
- 覆盖 13 工具及 Skill 注册、初次包资源读取、Origin 拒绝、断线／超时不重放、未决请求清理、设置冲突／未知键、客户端首屏及卸载／重载。
- 执行 typecheck、test、build；在精确宿主 peers 下完成隔离 carrier 和真实原生 Desktop 的六视图、浅深主题、窄窗口与键盘验收。已有 96 项业务测试和目标工具／Skill 类型检查仅作为原基线，不延伸为本版兼容通过。
- 交付运行改动时计划为 Agenda 0.4.0，验证本地可安装 .tgz 的宿主／客户端／Skill／资源完整性；源码缺产物不能宣称公开 Git 来源已可安装。补真实 repository，公开推送／发布另按授权执行。
- Desktop 候选精确提交／包版本单列，未完成整套组合时不把新版运行代码写入旧核心正式锁；纯文档提交包仍为 0.3.0，可以按原组合同步文档 commit。快照、verified／verifiedWith 以实际验证为准。
