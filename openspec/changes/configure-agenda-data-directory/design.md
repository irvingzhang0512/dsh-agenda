## Context

日程宿主目前以空配置模式启动，通过 resolveDataDir 选择目录。服务、存储、备份与节假日监听器均在启动时建立，A005 和 F008 是存储契约来源。

## Goals / Non-Goals

为管理员提供一个可持久配置的用户级目录。保留现有安装的缺省解析、文本格式、锁、设置修订和跨会话共享语义。

## Decisions

宿主配置 dataDir 为可选字符串，指定时须为本机绝对目录，空值沿用环境规则。服务重启后新值生效。显式路径相对、指向普通文件或无法访问时，报告配置错误并中止该插件的存储初始化。切换配置本身不触发旧文件复制；新环境可初始化空目录，旧环境由维护者先准备好已有资料。

将解析结果作为唯一存储根传给 CsvAgendaStorage。服务报告的目录、备份目录与节假日监听和重载引用同一结果。dataDir 属于宿主配置，日历界面的业务设置补丁继续沿用原字段范围。公开文档和测试只使用合成样例。

## Risks / Trade-offs

显式路径拼错可能创建空目录。已有环境的维护工具应在切换前核验源和目标，并在重开后读回服务实际位置与已有业务资料。
