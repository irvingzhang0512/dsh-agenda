# 日程插件可指定数据目录 v1

## Why

现行插件从宿主环境选择用户级目录。管理多个插件时，维护者需要为日程单独指定持久目录。文档版 v1 待确认。

## What Changes

宿主配置增加可选 `dataDir`。配置生效后，服务、文件写入、备份和节假日监听共用指定目录；留空时兼容已有安装。文件迁移由管理该环境的一方执行。

## Capabilities

### Modified Capabilities

- `agenda-service-storage` 调整 F008 和 A005 的目录选择顺序，沿用 CSV、YAML、并发写入与恢复契约。

## Impact

仅涉及日程插件的宿主配置、存储初始化、测试及使用说明。宿主 API、客户端操作和业务文件格式沿用现行契约。
