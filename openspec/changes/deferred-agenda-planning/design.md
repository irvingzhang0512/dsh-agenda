# 候选设计与未决项

## Context

历史原文只读保留，当前实现契约见本库 openspec/specs 与 MIGRATION.md。本文件不把候选接口、配置键或命令描述为已经可运行。

## Goals / Non-Goals

目标是保留历史需求并建立后续细化、确认、实现和验证入口；本轮不开发业务、不改数据、不安装、不运行任务。

## Decisions

- 优先级、截止时间与提醒不因原文提到就加入现有模型；提醒在另一候选变更。
- 拖动需确定全天/定时、跨日/时区、重复实例与撤销。
- Todo转Event需决定保留/关联/删除原待办、完成状态和回滚。
- 趋势/密度需决定度量、实例计数及范围。
- JSONL/SQLite/远端存储只是原文§15扩展可能，不是改掉CSV的要求。
- 协作和第三方日历集成保持非目标，后续另提案。

## Risks / Trade-offs

历史愿望并非完整设计，不能用空缺处的默认推测替代用户确认。任何接口/配置/存储变化需列明旧值去向、失效字段清理、完整引用、备份、CAS、恢复与回滚；不静默改已有资料。

## Migration Plan

目前无业务迁移执行计划。文档版确认后再设计实际数据迁移，先预览、验证备份和冲突，实施状态与实测证据分开记录。

## Open Questions

需选择能力，确认拖动/撤销、优先级/默认、截止时间历法时区、Todo转Event原记录去向、统计定义；外部同步与复杂RRULE不自动获批。
