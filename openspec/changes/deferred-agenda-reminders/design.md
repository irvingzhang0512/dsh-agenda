# 候选设计与未决项

## Context

历史原文只读保留，当前实现契约见本库 openspec/specs 与 MIGRATION.md。本文件不把候选接口、配置键或命令描述为已经可运行。

## Goals / Non-Goals

目标是保留历史需求并建立后续细化、确认、实现和验证入口；本轮不开发业务、不改数据、不安装、不运行任务。

## Decisions

- 重复事件与重复待办分开；现有事件none仍为当前能力。
- 原始例子包括提前10分钟、1小时和自定义时间，只是触发意图，尚无可执行语法。
- 提醒逻辑与微信等通知渠道分离，渠道凭据只在本机安全所有者保存。
- 在线定时更新节假日已由F010替代且撤回，不在此恢复。
- 重复规则、单次/整组编辑、删除例外、时区/跨日/农历、关机错过、去重及失败重试均待明确。

## Risks / Trade-offs

历史愿望并非完整设计，不能用空缺处的默认推测替代用户确认。任何接口/配置/存储变化需列明旧值去向、失效字段清理、完整引用、备份、CAS、恢复与回滚；不静默改已有资料。

## Migration Plan

目前无业务迁移执行计划。文档版确认后再设计实际数据迁移，先预览、验证备份和冲突，实施状态与实测证据分开记录。

## Open Questions

需确认重复频率/结束条件/实例例外，提醒相对起点，本机或指定主机执行，渠道授权/错过策略/重试上限，以及是否由自动化调度。
