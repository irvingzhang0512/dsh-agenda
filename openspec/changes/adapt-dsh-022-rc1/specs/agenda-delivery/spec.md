# Spec Delta

## ADDED Requirements

### Requirement: 0.2.2 rc1 完整固定运行

插件 SHALL 在固定宿主 0.2.2-rc.1 以完整版本 0.2.2-rc.1+rev.1 交付，源码和运行资源可核验，保留原身份、接口与业务语义。

#### Scenario: 真实目标加载

- **WHEN** 目标宿主安装固定完整提交
- **THEN** 工具、Skill 及客户端按原职责加载，源码与完整产物一致，未验证服务保持待验

### Requirement: 0.2.2 rc1 领域行为保真

插件 SHALL 保持日历、公历／农历事件、待办、节假日、十三工具及 Skill 的既有行为；继续独立安装。

#### Scenario: 原资料读取与工具调用

- **WHEN** 目标宿主加载原 CSV/YAML 与日历入口
- **THEN** 事件／待办内容保持，十三工具信封和 Skill 可用，错误输入保持既有错误语义

### Requirement: 配置与资料保护

插件 SHALL 区分原始覆盖和实际生效配置，保留原字段、引用、资料和凭据；取消或冲突不写入，回退不覆盖后续业务。

#### Scenario: 继承及并发编辑

- **WHEN** 设置含默认／继承／表达式值，用户取消或原配置并发变化
- **THEN** 显示实际生效值，取消无写入、冲突拒绝；保存仅修改目标原始覆盖

#### Scenario: 停用与恢复

- **WHEN** 插件被停用、卸载或升级失败
- **THEN** 业务资料和原选择保留；不通过整目录恢复覆盖后续内容
