# Irving · 日程与待办

在 DSH 中查看公历与农历日历、节假日和调休，管理日程与待办，也可以让 Agent 用自然语言帮你操作。

## 能做什么

- 用月历、周历和今天视图查看安排，同时显示农历、节气与已收录的放假／调休信息。
- 记录日程和待办，按多级分类查找；待办支持重复规则和按日期完成。
- 搜索标题与分类，查看一段时间内的统计。
- 在会话中说出安排，Agent 通过工具操作同一份数据，页面同步更新。

## 安装

当前本地版本 **0.2.1-rc.2+rev.1**，适配 **DSH Desktop 0.2.1-rc.2**，不需要其他自研插件。宿主与依赖要求见 [package.json](package.json)。

截至 2026-10-18，[公开源码仓库](https://github.com/irvingzhang0512/dsh-agenda)默认分支包版本为 **0.3.0**；本页所述 0.2.1-rc.2+rev.1 尚未公开推送或发布。先向维护者获取对应版本的完整预构建 `.tgz`，目前没有本版公开下载链接。

1. 在 Desktop 打开「插件 → 添加插件 → 安装第三方插件」，填写该 `.tgz` 的本机绝对路径。
2. 核对包名 `dsh-agenda` 和版本 `0.2.1-rc.2+rev.1`，启用插件，按提示重启 DSH。
3. 点击左侧「日程」，确认今天页显示日期和农历。已安装本版的用户直接开始使用。

此前构建、测试和 Desktop 验证范围见 [兼容升级记录](docs/DSH-UPGRADE-20261017.md)，节假日与页面专项验收见 [0.4.0 验收记录](docs/VERIFICATION-0.4.0.md)。历史验收与本版公开安装分别记录。

## 配置

默认即可使用。在「插件 → Irving · 日程与待办 → 日程设置」可选择周一或周日作为周起始日。默认**周一**，点击「保存设置」后月历和周历即时更新；卡片还显示节假日库版本、收录年份和资料问题。

若提示其他窗口已修改设置，先核对当前值，再使用「重新读取」放弃当前设置草稿并加载最新值。

## 第一次使用

1. 点击「日程」，在今天页或月历中选定日期，点击「＋ 新建日程」。填写标题「项目评审」及开始、结束时间，保存。
2. 在对应日期核对标题和时间，点击该日程可重新编辑。
3. 配置好可用模型后，也可以发送：

   > 明天下午三点到四点安排项目评审，分类是工作/项目。

   Agent 返回成功后，在明天的日历中核对日期、时间和分类。

## 常用操作

| 想做什么 | 怎么做 | 结果 |
|---|---|---|
| 记录农历生日 | 新建日程时选择农历并填写日期 | 换算为对应公历日期展示 |
| 管理每日待办 | 新建待办并选择每天重复 | 每天分别记录完成状态 |
| 查找安排 | 在搜索页填写标题或分类 | 返回匹配的日程与待办 |
| 查看工作量 | 在统计页选择本周、本月或自定义日期 | 显示该范围的统计 |

## 使用边界

- 节假日展示离线运行，使用随插件提供的 `chinese-days` 数据。未收录年份显示「放假安排未载入」，只按普通工作日／周末判断，不预测调休。
- 本地年度 YAML 可以覆盖资料，规则及新增年份的维护方式见 [节假日说明](docs/HOLIDAY-UPDATE-20261014.md)。读取不会覆盖原文件。
- 业务数据保存在 DSH 数据目录的 `agenda/` 下；日程／待办为 CSV，分类／设置为 YAML，写入带锁、原子替换并保留最近 10 份备份。
- 页面断线会拒绝新操作。已发送后超时表示结果待核对，重连不会自动重放写入。
- 本版不提供重复日程事件、到点提醒、微信通知或自动联网更新节假日；重复待办仍可使用。

## 常见问题

### Agent 说添加成功，日历里却没看到

先核对目标日期和当前筛选条件，切到对应月历或今天页刷新查看。若此前出现「结果未确认」，先搜索现有条目，确认没有重复后再决定是否重试。

### 明年的调休没有显示

在插件详情查看收录年份。未收录时等待含新年度资料的插件版本，或按节假日说明维护本地年度覆盖。
